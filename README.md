# Embedded hardware project
* Reduced a 4-layer PCB to a 2-layer PCB for cost-effective manufacturing.
* Designed and reviewed PCB implementation with consideration for component placement, grounding, power distribution, noise, isolation, thermal performance, signal integrity, manufacturability, and adherence to product requirements.
* Found a supplier for panel PCB fabrication and released the Gerber file to them.
* Prepared the BOM and stencil for production setup.
